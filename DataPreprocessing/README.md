# ManyDaughters replication materials: data preprocessing

Last updated: 25 August 2026

## Overview

This directory contains the data-preprocessing component of the replication materials for:

> Albrecht et al. (2026), “The Effect of Data Access on Pre-Analysis Plans: Evidence from a many-analyst study on the daughters hypothesis.” Working paper; journal and DOI not yet available.

The complete author list is provided in the manuscript. This component combines Stata and Python code to prepare the pseudonymized project-survey data, rerun research-team (RT) analyses based on licensed SOEP data, collect RT results, and combine idiosyncrasy-analysis results.

The public package contains the inputs and intermediate results needed to regenerate the preprocessed data which is used for the preregistered analysis in the paper. Licensed German Socio-Economic Panel (SOEP) microdata and SOEP-derived samples are not included. A rerun of any RT-analysis requires acquiring the licensed SOEP data and can as such not be accomplished in a plug-and-play fashion with these replication materials alone. None of the files generated by this preprocessing part of the replication materials maps directly to a particular table, figure, or in-text result in the manuscript; its datasets are inputs to downstream analysis components. A manuscript-output mapping is provided in the replication materials for our preregistered analysis.

From the project root, the public preprocessing output is reproduced by running:

```stata
do code/0_main.do
```

### SOEP-Core v37

The study uses the International Scientific Use Version of SOEP-Core v37, covering 1984–2020. The migration and refugee samples are excluded. The source microdata and the projects’ 100%, 5%, and 95% SOEP-derived samples are not redistributed.

SOEP-Core v37 can be requested from DIW Berlin by registered scientific users. Replicators must place the obtained files in the directories described by the `ContentDescription.txt` files under `data/raw_confidential/` and `data/derived_confidential/`. See the [SOEP-Core v37 editions](https://www.diw.de/en/diw_01.c.838852.en/edition/soep-core_v37_-_further_editions.html) and [SOEP ordering information](https://www.diw.de/en/diw_01.c.839040.en/soep-core_data_1984-2020__v37__available.html).

Data citation:

> Socio-Economic Panel (SOEP), data for years 1984–2020, SOEP-Core v37, International Scientific Use Version, 2022. https://doi.org/10.5684/soep.core.v37i

### ManyDaughters project surveys

The project surveys were administered through Prolific to participants who applied and were later admitted to become RT members in the ManyDaughters many-analyst study. Participants gave active consent. The IRB review board at the Department of Economics at the University of Oxford approved the research under reference `ECONCIA23-24-19 Amend1` on 3 March 2025.

The public input is `data/raw/surveys/merged_survey_raw-data_pseudonymized.dta`. It combines the pseudonymized project-survey and project-tracking information required by this preprocessing component.

### RT submissions and results

RT do-files originated from participating research teams. The public package contains the submitted do-files, consistency-checked variants used for reruns, and the resulting 5%, 95%, and idiosyncrasy result files. Personal names in public do-files were replaced with `[REDACTED]`; see `data/raw/dofiles_consistency_checked/RedactionNote.txt`.

The original idiosyncrasy execution logs were produced from unredacted RT do-files and may contain names. They are therefore omitted. `data/derived/5_idiosyncrasy_logs/` intentionally contains only `RedactionNote.txt`.

### Manual PAP-to-code consistency reviews

`PAPtoCode_ConsistencyCheck_10%sample_results.xlsx` and `PAPtoCode_ConsistencyCheck_100%sample_results.xlsx` are author-generated datasets. They record manual reviews of RT submissions conducted by an independent research assistant.

## Repository structure

```text
code/                         Numbered scripts in workflow order

data/raw/                     Public or pseudonymized inputs and redacted RT do-files
data/raw_confidential/        Descriptions of omitted licensed SOEP inputs
data/derived/                 Results from RT analyses and generated combined datasets
data/derived_confidential/    Descriptions of omitted SOEP-derived datasets

README_IDIOSYNCRASY.md        Detailed idiosyncrasy workflow guide
```

Only numbered workflow scripts strictly needed to reproduce all preprocessing steps are kept directly in `code/`. Supplemental Python utilities without a workflow-number prefix are in `code/auxiliary/`.

## Computational requirements

### Software

The public aggregation workflow requires Stata 19 or StataNow 19. `08_collect_RT_results_idiosyncrasy.do` uses Windows shell commands; rebuilding the combined idiosyncrasy dataset is therefore Windows-oriented.

Optional public-package Python utilities were reproduced in the included `.venv` with Python 3.13.0 and the following direct dependencies:

| Package | Version |
| --- | --- |
| `python-dotenv` | 1.2.3 |
| `psutil` | 7.2.2 |
| `pandas` | 3.0.5 |
| `plotly` | 6.9.0 |
| `dash` | 4.4.1 |
| `Resource` | 0.2.1 |

The SOEP-dependent RT and idiosyncrasy reruns were performed in a separate Python environment. RT do-files require a variety of Stata packages. Each RT do-file documents its own dependencies and installs the required packages when rerun.

For users other than the originally configured project user, set the Stata executable in the environment or in a project-root `.env` file:

```text
STATA_EXECUTABLE=C:/Program Files/StataNow19/StataMP-64.exe
```

The Python runners derive paths from the current working directory. Run all commands from the `DataPreprocessing` project root.

### Python setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Controlled randomness

The distributed sample-construction code uses deterministic seeds:

- `code/01_SOEP-dataset_creation.do` sets seed `24082026` before drawing the 5% household sample. The complementary observations form the 95% sample. Note this seed is deliberately different than the one we used. We need to prevent exact reproducibility of our 5%-samples and 95%-samples of SOEP data as they would threaten anonymity of RT-outcomes such as do-files and results.
- `data/raw/dofiles_consistency_checked/5%-idiosyncrasy_Setup.do` sets the seed to `123 + iteration`, giving seeds 123 through 1123 for iterations 0 through 1000.
- Individual RT do-files may use additional stochastic procedures. Their seeds and package-specific randomness are documented in the respective do-files.

### Hardware, runtime, memory, and storage

Historical benchmarks were obtained on a 64-bit Windows 11 Enterprise laptop with an AMD Ryzen 7 PRO 8840HS processor (8 physical cores, 16 logical processors), 64 GB RAM, and a 1 TB NVMe SSD.

| Step | Approximate historical runtime |
| --- | --- |
| `05_data_import.do` | 5–10 minutes |
| `06_collect_RT_results_05.do` | 5–10 minutes |
| `07_collect_RT_results_95.do` | 5–10 minutes |
| Current public `0_main.do` | Approximately 15–30 minutes |
| `08_collect_RT_results_idiosyncrasy.do` | 3–5 hours for approximately 484,000 CSV files |
| Complete 5% RT rerun | 3–4 hours |
| Complete 95% RT rerun | 24–48 hours |
| Idiosyncrasy execution | About one week per RT for four hypotheses × 1,001 iterations using one worker and no submission stagger |

A full idiosyncrasy rerun needs substantial temporary storage. Each concurrent worker can require up to approximately 10 GB for temporary SOEP subsamples; plan for at least `worker count × 10 GB`, plus result, log, and filesystem overhead. Runtime depends strongly on RT code, worker count, Stata version, storage speed, and network contention.

## Description of programs

| Program | Purpose | Usable from the public package alone? |
| --- | --- | --- |
| `code/01_SOEP-dataset_creation.do` | Creates the restricted 100%, 5%, and 95% SOEP samples and derived analysis datasets | No; licensed SOEP inputs are omitted |
| `code/02_run_RT_analysis_05.py` | Reruns RT do-files in `dofiles_analysis/` on the 5% sample | No; restricted sample data are required |
| `code/03_run_RT_analysis_95.py` | Reruns RT do-files in `dofiles_analysis/` on the 95% sample | No; restricted sample data are required |
| `code/04_prepare_idiosyncrasy_index_5.py` | Runs selected RT hypotheses over repeated 5% samples | No; restricted or separately presampled data are required |
| `code/05_data_import.do` | Loads the pseudonymized project-survey dataset | Yes |
| `code/06_collect_RT_results_05.do` | Collects the 5% result CSVs | Yes |
| `code/07_collect_RT_results_95.do` | Collects the 95% result CSVs | Yes |
| `code/08_collect_RT_results_idiosyncrasy.do` | Recursively collects the idiosyncrasy result CSVs | Yes; long-running |

The ordinary 5% and 95% runners read RT do-files directly from `data/raw/dofiles_consistency_checked/dofiles_analysis/`. They do not use the idiosyncrasy staging procedure described in [README_IDIOSYNCRASY.md](README_IDIOSYNCRASY.md).

Auxiliary monitoring, reporting, and maintenance utilities are stored under `code/auxiliary/` and documented in the idiosyncrasy guide.

## Instructions to replicators

### Reproduce the public preprocessing dataset and the combined idiosyncrasy dataset

1. Download the complete `DataPreprocessing` directory without changing its internal structure.
2. Install Stata 19 or StataNow 19.
3. Set the working directory to the `DataPreprocessing` project root.
4. Run:

   ```stata
   do code/0_main.do
   ```

The main do-file performs the following steps in order:

1. `05_data_import.do` loads `data/raw/surveys/merged_survey_raw-data_pseudonymized.dta`.
2. `06_collect_RT_results_05.do` collects the 5% RT results.
3. `07_collect_RT_results_95.do` collects the 95% RT results.
4. Stata writes `data/derived/ManyDaughters_preprocessed.dta`.
5. `08_collect_RT_results_idiosyncrasy.do` collect the idiosyncrasy results.
6. Stata writes `data/derived/idiosyncrasy_results_combined.dta`.

`01_SOEP-dataset_creation.do` is intentionally commented out in `0_main.do`, and `02_run_RT_analysis_05.py`, `03_run_RT_analysis_95.py` as well as `04_prepare_idiosyncrasy_index_5.py` are intentionally kept outside of the `0_main.do` workflow. This do-file and these srcipts require licensed SOEP data.


### Full rerun with licensed SOEP data

After obtaining SOEP-Core v37 and populating the directories described by the `ContentDescription.txt` files:

1. Run `code/01_SOEP-dataset_creation.do` to create the 100%, 5%, and 95% samples.
2. Run `python code/02_run_RT_analysis_05.py`.
3. Run `python code/03_run_RT_analysis_95.py`.
4. Follow [README_IDIOSYNCRASY.md](README_IDIOSYNCRASY.md) if the repeated-sample idiosyncrasy results must also be regenerated.
5. Run `code/0_main.do`, and run `code/08_collect_RT_results_idiosyncrasy.do` separately if required.
