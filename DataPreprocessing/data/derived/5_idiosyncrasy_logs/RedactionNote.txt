This folder would contain log files from running the RT do-files for
1,000 iterations on redrawn 5% samples, i.e. log files generated by the
execution of 04_prepare_idiosyncrasy_index_5.py.

In total, there are more than 400,000 log files. We abstain from
publishing these log files as part of the replication materials. We ran
04_prepare_idiosyncrasy_index_5.py using unredacted do-files from RTs;
i.e. many of these do-files, and therefore also the corresponding log
files, contain names of RTs that we promised to anonymize for
publication.
