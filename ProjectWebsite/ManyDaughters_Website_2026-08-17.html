#ManyDaughters
Impact of Having Daughters on Attitudes, Preferences, and Behaviors
Design and submit pre-analysis plans (PAPs) and analysis code to test four hypotheses on the potential effects of having daughters on various outcomes, using SOEP data— and join as co-author.
Project overview
Researchers worldwide are invited to test a shared set of hypotheses on how having daughters influences behavior and preferences, using data from the German Socio-Economic Panel (SOEP). Research teams (RTs) will submit pre-analysis plans (PAPs) and analysis codes.
The project coordinators (PCs) will implement submitted analysis codes and analyze the results to gain insights into both the scientific process as well as the impact of having daughters on various outcomes. They will study variation in analytical choices and findings, and write a metascience paper on the topic. All RTs whose analysis codes are implemented will also be included as co-authors.
