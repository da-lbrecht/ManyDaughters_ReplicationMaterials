# ManyDaughters replication materials

This repository contains the replication materials for:

> Albrecht et al. (2026), “The Effect of Data Access on Pre-Analysis Plans: Evidence from a Many-Analyst Study on the Daughters Hypothesis.” Working paper; journal and DOI not yet available.

This top-level README provides a brief guide to the repository. Detailed documentation—including data provenance, software requirements, and reproduction instructions—is provided in the `DataPreprocessing` and `DataAnalysis` directories.

## Repository structure

| Directory | Contents |
| --- | --- |
| [`DataPreprocessing`](DataPreprocessing/) | Data preparation, research-team analysis reruns, and aggregation of results. See its [README](DataPreprocessing/README.md) for detailed instructions. |
| [`DataAnalysis`](DataAnalysis/) | Analyses used to produce the results reported in the manuscript. Detailed documentation will be provided within this directory. |
| [`RT-PAPs`](RT-PAPs/) | Pre-analysis plans submitted by the participating research teams. |
| [`RT-PAP-Comments`](RT-PAP-Comments/) | Supplementary comments RT pre-analysis plans submitted by RTs on a voluntary basis. |
| [`Communications`](Communications/) | Project recruitment and standardized communication materials. |
| [`ProjectWebsite`](ProjectWebsite/) | Archived snapshot of the project website. |
